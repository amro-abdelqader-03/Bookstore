# Book Haven

A small front-end bookstore website built with HTML, CSS, and JavaScript.

## Overview
This project contains a landing page for a library/bookstore called Book Haven, including a hero section, book categories, and a borrow button that prompts the user for membership and book details.

## Project structure
- index.html: main storefront page
- css/style.css: styling for the layout and design
- script/app.js: JavaScript for the borrow flow
- exercises/: practice tasks and mini exercises for JavaScript development

## Run it
Open index.html in a browser to view the site.

## Notes
The project is a simple static website intended for learning and practice.
